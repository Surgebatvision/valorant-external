# Valorant External

Download: soon

External package for Valorant: nothing injected, overlay only.

Modules: soft aim, ESP, triggerbot, radar, config system. Aim has bone priority and a smoothing slider, ESP has skeleton and health, radar is a moving minimap, triggerbot has delay control.

- Windows 10/11, Riot Client
- Administrator rights for the loader
- Borderless required

Vanguard is picky, so attach before the match and keep the profile light.
